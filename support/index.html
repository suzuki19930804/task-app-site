サポート

「タスク」アプリについてのご質問・不具合のご報告は、GitHub の Issues からお寄せください（GitHub のアカウントが必要です）。いただいた内容は公開されるので、個人情報やタスクの内容は書かないでください。

アプリの使い方は、アプリの「設定」→「使い方・ヘルプ」にもまとめています。

よくある質問

機種変更したら完全版が使えなくなりました
新しい端末で、購入したときと同じ Apple ID でサインインし、アプリの「設定」→「完全版」→「購入を復元」を押してください。
データを新しい iPhone に移したい
古い端末の「設定」→「データを書き出す」でファイルに保存し、新しい端末の「データを読み込む」で選びます。完全版なら「iCloud で同期」でも引き継げます。
間違えてデータを消してしまいました
アプリは起動のたびと更新のたびに、端末の中に自動でバックアップを残しています。「設定」→「自動バックアップから戻す」で戻せます。
パソコンでも使いたい
Web 版をブラウザで開いてください。完全版の iPhone で「フォルダで同期」を使い、Web 版（Chrome・Edge）の設定で同じファイルを選ぶと自動で同期します。Safari・Firefox では「書き出す」「読み込む」でデータを受け渡せます。
無料版で 4 つめのタスクが作れません
無料版はタスク 3 つまでです。今あるタスクにやることを追加するか、完全版をご検討ください。今あるデータが消えることはありません。

English

For questions or bug reports about the app, please open an issue on GitHub Issues (a GitHub account is required). Issues are public, so please don't include personal information or the contents of your tasks.

The Full Version stopped working after I changed devices
Sign in with the same Apple ID you used to buy it, then tap Settings > Full Version > Restore Purchase.
How do I move my data to a new iPhone?
Use Settings > Export Data on the old device and Import Data on the new one. With the Full Version, Sync with iCloud also works.
I deleted data by mistake
The app keeps automatic backups on your device. Use Settings > Restore from Automatic Backup.
